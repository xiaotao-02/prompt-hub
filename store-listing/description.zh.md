做 AI 绘画时，最费时间往往不是「画」，而是把一张参考图变成可用、可复制、格式对口的提示词。Prompt Hub 让你在浏览网页时就能开工：看中参考图的造型、光影与构图，右键即可收集到浮动参考面板，或跳过收集直接反推；几秒内在页面右下角拿到可复制结果，粘贴到 Stable Diffusion、Midjourney、Flux 等工具即可。

你只需在设置页配置自己的视觉模型 API Key 与端点；扩展不向开发者后端上传内容与密钥，数据流细节见下文「隐私与数据传输」。装好以后，可在面板内对话改写、切换策略档位、版本回溯；大图编辑与 AI 调整也可在选项页「提示词库」中完成。

输入涵盖 PNG / JPEG、GIF / APNG / 动画 WebP，以及 Twitter、Reddit、Discord 等平台常见的「假 GIF」<video> 元素；画布、内联 SVG、CSS 背景图等同样在支持列表中。站点劫持右键时，可用 Ctrl+Shift+E 框选区域，或 popup 内「截取区域添加到参考」作为兜底。

✦ 主要特性
━━━━━━━━━━━━━━━━━━━━━━

▸ 右键与快捷键
• 右键任意 <img> / <video> / <canvas> / 内联 SVG / CSS 背景图都能识别
• 菜单项：「添加到参考」（收集后合成反推）或「直接反推提示词」（跳过收集）
• Ctrl+Shift+E（Mac：Command+Shift+E）框选矩形区域截图加入参考
• popup 内也可一键启动区域截图；页面空白处右键有「截取区域添加到参考」

▸ 参考面板与多图合成
• 最多收集 8 张参考图，在浮动面板中综合理解后输出一条提示词
• 「生成提示词」完整反推；「提取材质 / 提取风格」收窄维度
• 视频可在指定时间区间内按播放进度采样多帧，生成分镜式提示词

▸ 动图与视频原生支持
• GIF / APNG / 动画 WebP 自动扁平化为静态首帧再送给视觉模型
• <video> 元素（含 Twitter / Reddit / Discord 把 GIF 转成的 mp4 假 GIF）通过 canvas 抓取当前播放帧
• Canvas、内联 SVG、CSS background-image / mask-image 也都能识别

▸ 输出风格与反推策略
• 四种输出风格：自然语言中文段落 / 英文段落 / Stable Diffusion tag / Midjourney 风格
• 多档反推策略可选：经典策略、v0.2.2、v0.3.0、v0.3.5、v0.3.6 通用高还原（默认）、原生识别、自定义组合
• 原生识别：图像直送 VLM 极简直出，不走输出风格四档
• 自定义组合：自由混搭指令集 / 采样 / 拼接三组件版本，适合对比实验

▸ 编辑、AI 调整与历史
• 浮动面板内直接修改提示词，自动按版本保存，可一键恢复任一历史版本
• 对话式 AI 调整：用一句话告诉插件「改得更电影感 / 翻译成英文 / 加 8k masterpiece」，模型会基于现有提示词重写并自动存为新版本
• 选项页「提示词库」：大图编辑、文件夹管理、AI 调整与版本浏览
• popup 弹窗内查看、复制、删除最近 100 条本地历史

▸ 模型配置（在「设置」中自行填写）
• 支持 OpenAI Chat Completions 协议兼容的视觉大模型端点
• 可填写自定义 Base URL（自部署或兼容网关）
• 设置页支持粘贴 Key 一键导入，可识别 curl 等配置片段

▸ 配置与同步
• API Key 仅保存在本地浏览器（chrome.storage），通过 Chrome 自带的 storage.sync 在同一 Google 账号设备间加密同步
• 设置 → 检查更新：手动比对 GitHub Release，提示是否有新版可下载

✦ 常见问题
━━━━━━━━━━━━━━━━━━━━━━

Q：右键菜单怎么变了？
A：现分为「添加到参考」（先收集、再在面板生成）和「直接反推提示词」（跳过收集立即反推）。需要多图合成时请先「添加到参考」。

Q：为什么部分网站图片报「下载图片失败」？
A：少数站点对图片做了 Referer 防盗链。可右键「在新标签页打开图片」再重新提取。

Q：图片太大失败？
A：扩展内置 8MB 上限，动图 / 视频帧已经在送出前自动缩到最长边 1280~1536px。

Q：Twitter / X 的 GIF 没反应？
A：这些「GIF」其实是 <video> 元素，请直接在视频画面上右键；菜单文案会是「添加到参考」或「直接反推提示词」。

Q：视频帧抓不到？
A：少数跨域视频没有 crossorigin="anonymous"，canvas 会被污染、无法导出帧。建议把视频暂停在想要识别的画面后再右键；或改用区域截图。

Q：某些模型无法识图？
A：请选用支持图像输入的视觉大模型；纯文本 chat 接口无法完成识图反推。

Q：模型报错或说「没看到图」？
A：请选用支持 image_url 的多模态视觉模型，勿用纯文本模型做识图反推。

Q：安装时出现「增强型安全浏览功能不信任此扩展程序」？
A：若你开启了 Chrome「安全浏览 · 增强型保护」，系统可能对尚未完成信任积累的开发者额外提示（官方说明：https://support.google.com/chrome_webstore/answer/2664769?hl=zh-Hans）。这不等于认定扩展有害，仍可点「继续安装」正常使用。
