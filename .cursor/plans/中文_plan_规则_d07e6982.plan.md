# 创建"Plan 使用中文"Workspace 规则

## 目标

在 `.cursor/rules/plan-language.mdc` 新增一条 `alwaysApply: true` 的规则，让 Cursor AI 在任何对话中调用 `CreatePlan` 工具时都以中文撰写内容。

## 规则文件

- 路径：[`.cursor/rules/plan-language.mdc`](.cursor/rules/plan-language.mdc)
- 前置字段：`alwaysApply: true`，无 `globs`
- 内容：明确要求 Plan 的标题、概述、任务列表、正文全部使用中文；代码块、命令、文件路径保持原样不翻译

## 规则草稿

```markdown
---
description: 要求 AI 创建的所有 Plan 使用中文
alwaysApply: true
---

# Plan 语言约定

调用 CreatePlan 工具时，**所有文字内容必须使用中文**，包括：

- plan 标题（name / overview）
- 计划正文（各章节标题、描述、步骤说明）
- todos 的 content 字段

下列内容**保持原样，不翻译**：

- 代码块、Shell 命令
- 文件路径、函数名、变量名
- 技术术语缩写（如 PR、CI、MV3、IDB）
```
